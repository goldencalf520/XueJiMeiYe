# XJ-203 · 乐龄版首页：墨绿大字号、家人入口前置、语音小镜条

> **归属**：前端页面 Agent（`fe`） · **波次**：W2 · 主 Tab 体验 · **优先级**：P1 · **规模**：M

> **价值**：乐龄用户是核心人群。他们需要的是「今天要做的 2 件小事」和「一键找家人」，而不是游戏化激励。

## 背景

- 项目已有 `.elder` 墨绿皮肤与「乐龄强制关闭动效」的约定，但首页仍与标准版共用同一套模块编排。
- 乐龄用户认知负荷预算更低，信息密度需要显著下调。

## 范围与实现要点

1. 乐龄首页模块替换为：「今天要做的 2 件小事」（而非 3 件）+ 家人入口前置 + 语音小镜条。
2. 按 D21：乐龄下保持原设计，**由底部语音条替代 `mirrorFab` 悬浮球**（避免遮挡大字内容），不叠加悬浮球。
3. 字号与触控热区放大（热区 ≥44px），图标与文字同步放大。
4. 游戏化元素（签到连击、积分、徽章、排行榜）在乐龄下不展示。
5. 动效档位强制为 `mo-off`，页面首帧即完整可读。
6. 语音小镜条提供「按住说话」入口，交互路径不超过一次点击。

## 验收标准

- [ ] 乐龄首页与标准首页在模块构成、字号、信息密度上有可截图证明的差异。
- [ ] 乐龄下无任何入场动画（档位为 `mo-off`）。
- [ ] 家人入口在首屏可见，无需滚动。
- [ ] 触控热区实测 ≥44px。
- [ ] 游戏化模块在乐龄下完全不渲染。
- [ ] 乐龄首页**不出现 `mirrorFab` 悬浮球**（由底部语音条替代，按 D21）。

## 禁止事项

- ⛔ 不要给乐龄强行保留游戏化元素。
- ⛔ 不要提供乐龄动效的手动覆盖入口（按 D10，乐龄强制 `off`）。
- ⛔ 不要在乐龄首页同时保留语音条与 `mirrorFab`（按 D21，仅语音条）。
