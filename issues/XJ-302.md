## 背景

- 现有 `GET /app/checkins`（app.controller.ts:537）返回的字段不足以渲染月历网格与连签进度。
- 周报需要六维环比的周聚合，目前没有对应接口。
- 档案页需要「人话结论」，但结论口径必须与六维算法同源（D20），不能由前端推断。

## 范围与实现要点

1. 扩展 `GET /app/checkins`：新增 `streakDays`（连续签到天数）与 `monthSignedDates`（本月已签日期数组）。
2. 新增 `GET /app/archive/weekly?week=`：返回当周指数、环比、三件事（复用 assess 的 `three` 结构）、六维变化数组。
3. 按 D20 在档案 / 趋势接口补齐结论字段：`verdict`（一句人话结论，如「达标 55%」「略高于预期」）与 `targetPct`（达标百分比），口径必须与六维算法同源。
4. 周报数据复用 `archive.service.ts` 已有聚合能力，不新建数据表。
5. 接口在 `docs` 或 PR 描述中给出**完整响应示例**（前端按此并行开发）。
6. 按 D5 本期只做站内数据，不引入订阅消息推送；推送需求另开 Issue，不并入本 Issue。

## 验收标准

- [ ] 两个接口的响应结构在 PR 中有示例，且与设计文档字段名一致。
- [ ] 空数据（新用户 / 无记录周）有兜底结构，不返回 null 导致前端崩。
- [ ] 周报「上一期」可通过 `week` 参数获取。
- [ ] `verdict` / `targetPct` 与六维算法口径一致，同一指标在档案页与周报中结论相同（D20）。
- [ ] 接口有权限校验（仅本人数据）。
