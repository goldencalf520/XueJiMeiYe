## 背景

- 现有 `pkg-points/checkin.vue` 仅 69 行，是一个简单打卡按钮，没有日历、没有连签激励、没有里程碑。
- 后端已支持扩展字段（XJ-302 提供 `streakDays` 与 `monthSignedDates`）。

## 范围与实现要点

1. 顶部连签卡：金色渐变；左「已连续签到 N 天」大数字，右「本月已签 M 天」。
2. 月历网格（`CalendarGrid.vue`）：7 列；已签 = 金底实心圆；今日 = 白底 + 2px 金描边；过去未签 = 灰底；未来 = 浅灰。
3. 7 格奖励轨道（`RewardTrack.vue`）：+2 / +2 / +3 / +3 / +5 / +5 / 金蛋；金蛋格虚线描边 + 蛋形图形。
4. 「今日还可做」三项任务（睡眠 / 运动 / 喝水），已完成降级为灰字 + `✓`。
5. 里程碑：连签 7 / 14 / 30 天解锁金蛋（15 积分 + 门店体验券）。
6. 动效：签到成功 `+5` 上浮淡出 600ms；金蛋格 `scale` 脉冲（`mo-off` 下静止）。
7. 漏签只显示「从今天继续」，不做中断惩罚提示。

## 验收标准

- [ ] 四种日期状态（已签 / 今日 / 过去未签 / 未来）在同一屏内视觉可辨。
- [ ] 连签天数与本月已签天数与后端数据一致。
- [ ] 签到成功有 `+5` 上浮动画，乐龄下无动画但仍清晰显示积分变化。
- [ ] 金蛋格在未解锁 / 已解锁两态下样式不同。
- [ ] 与 XJ-401 关联的入口（首页签到条）跳转可达。

## 禁止事项

- ⛔ 不要做倒计时催促或连签中断惩罚（健康产品不做焦虑驱动）。
- ⛔ 不要新增数据表（签到复用现有 `Checkin` 模型与积分流水）。
- ⛔ 不要在日历网格里为每个日期绑定独立事件处理导致性能问题——用事件委托。
