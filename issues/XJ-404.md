## 背景

- `pkg-game/wheel.vue` 已有积分转盘，抽奖模型与概率框架可复用。
- 差异化要求：转盘主打积分，盲盒主打知识卡收藏，入口文案与图标必须区分，避免同质。

## 范围与实现要点

1. 头部：标题 + 副标 + 右上「今日剩余 N 次」。
2. 盲盒区：可拆盒 = 金色渐变 + 十字缎带；待解锁 = 灰底虚线 + 灰度图形。
3. 奖品说明：健康知识卡（常见）/ 积分 5·10·20（常见）/ 门店体验券（稀有，玫瑰红标识）。
4. 次数获取说明：今日签到 +1 / 完成 1 项任务 +1 / 与家人接力成功 +1。
5. 主按钮「拆一个盲盒」+ 副标「每日免费 1 次」。
6. 开盒动效：分层元素合成（盒盖抬起 + 内容弹入 + 光晕），`mo-off` 下直接呈现结果。
7. 合规：概率公示在页面内；知识卡标注「不构成医学建议」。

## 验收标准

- [ ] 盲盒三种状态（可拆 / 待解锁 / 已拆完今日次数）正确展示。
- [ ] 开盒后有明确的奖品呈现，稀有奖品有差异化标识。
- [ ] 概率公示在页面内可查。
- [ ] 知识卡底部有「不构成医学建议」声明。
- [ ] 与积分转盘在入口文案、图标、主色调上有可见区分。
