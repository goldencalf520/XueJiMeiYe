## 背景

- 全站当前只有 4 个 keyframes、7 个文件有 transition，几乎等于没有动效体系。
- 动效底座已落地（`style/motion.scss` + `xj/motion.ts` + `XReveal`），页面只需加类。

## 范围与实现要点

1. 按 docs/08 §4 编排表：trend = 滚动触发 ●、加载 ●；report = 滚动 ●、加载 ●；timeline = 滚动 ●；hospital = 全项精简。
2. 接入方式优先用「模板加类」（`mo-rise` / `mo-d1~6` / `mo-reveal` + `is-in`），滚动触发只在首屏以下使用。
3. 时间轴加彩色节点（用语义色令牌）。
4. 报告页异常项高亮（用 `--meter-low` 系）。
5. 加载态补骨架屏，形状与真实内容对应。
6. 按压反馈统一用 `hover-class="mo-press-active"` + `hover-stay-time="80"`。

## 验收标准

- [ ] 四个页面在 `mo-full` 下有入场与滚动触发，在 `mo-off` 下首帧即完整可读。
- [ ] 滚动触发只播一次，且通过 `uni.createIntersectionObserver` 实现（无 `onPageScroll`）。
- [ ] 加载态骨架与真实内容形状匹配，无尺寸跳变。
- [ ] 改动仅限本 Issue 独占的四个文件（不超过必要范围）。
