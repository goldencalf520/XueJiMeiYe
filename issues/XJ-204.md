## 背景

- 项目已存在 `.night` 臻享夜色金皮肤，但目前没有触发入口，等于闲置。
- 全部 49 个页面都绑定了 `:class="xj.pageClass"`，这是零改动下发皮肤的最佳注入点。

## 范围与实现要点

1. 在 `xj/store.ts` 的 `pageClass` 计算属性中，当会员等级为 A 时追加 `night` class 与 `std`/`elder` 组合。
2. 按 D6 在「我的 → 设置」保留浅色可切换选项；用户显式选择优先于等级默认。
3. 校验夜色金下所有既有令牌（含 XJ-102 新增项）的可读性，必要时提高亮度补偿。
4. 白字 / 金底对比度必须达标（金底统一配深棕墨字 `--on-brand`，白字对比仅 2.4:1 不达 WCAG）。

## 验收标准

- [ ] A 级用户登录后全站呈夜色金（4 个主 Tab + 抽查 5 个分包页面）。
- [ ] B / C / 访客不受影响。
- [ ] 乐龄 + A 级的组合行为明确且合理（需在 Issue 内给出结论）。
- [ ] 所有文字对比度达标（提供数值表）。

## 禁止事项

- ⛔ 不要在页面里逐页写皮肤判断——必须走 `pageClass` 单点下发。
- ⛔ 不要降低既有令牌的可读性来「凑」夜色金效果。
