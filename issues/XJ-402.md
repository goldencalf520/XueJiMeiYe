# XJ-402 · 健康接力棒：与家人互接的健康打卡

> **归属**：前端页面 Agent（`fe`） · **波次**：W4 · 互动玩法 · **优先级**：P1 · **规模**：M

> **价值**：家人是乐龄用户最强的维系纽带。接力棒把「我做健康」变成「我们一起做健康」，且双方都有即时收益。

## 背景

- 项目已有 `FamilyLink` 与家人相关页面，但没有「共同行为」的机制。
- 设计要点：接力中断**不做惩罚**，断签日标记为「休息日」，避免给乐龄用户压力。

## 范围与实现要点

1. 接力状态卡：墨绿渐变；「你和 XX 的接力」+ 连续天数 + 今日是否待接棒。
2. 接力环：左「我」头像 + 中间虚线连接 + 握手图形 + 右家人头像（含已接棒时间）；头像复用 `XMascot`。
3. 规则说明区：接棒后双方各得 5 积分；一天一次，0 点重置。
4. 本周接力：7 格；已接 = 墨绿 `✓`；休息 = 灰「休」；今日 = 虚线描边「今」。
5. 主按钮：「接棒打卡」金色渐变，副标「我 +5 · 女儿 +5」（按实际家人关系生成称呼）。
6. 入口同时挂在 `pkg-family/list` 顶部（该文件由 XJ-705 负责，本 Issue 只提供组件与用法说明）。

## 验收标准

- [ ] 接棒成功后双方积分各 +5，页面即时刷新。
- [ ] 同一天重复接棒被拒并有友好提示。
- [ ] 休息日显示为「休」而非「漏」；页面无任何惩罚性文案。
- [ ] 未绑定家人时展示引导去绑定的空状态。
- [ ] 与首页乐龄家人卡的数据一致。

## 禁止事项

- ⛔ 不要做中断惩罚、连续天数归零提示。
- ⛔ 不要在接力环里使用图片资源（头像用 XMascot 合成）。
- ⛔ 不要修改 `pkg-family/list.vue`（属 XJ-705）。
