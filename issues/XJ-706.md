## 背景

- `pkg-me/tier.vue` 已有权益对比表，但当前等级列没有视觉强调。
- 按 D9，设置页需要新增「省流模式」显式开关（默认跟随设备自动判定）。

## 范围与实现要点

1. 等级页：权益表高亮当前等级列；升级进度条与「还差 N 积分」。
2. 设置页：新增「省流模式」开关（D9），与 `xj/motion.ts` 的档位机制联动；说明文案需让用户看懂「省流 = 少动画」。
3. 消息中心 / 预约记录：列表项入场错峰 + 加载骨架。
4. 顾问页：优先响应承诺做成可视化（如「4 小时内响应」标识）。
5. 记忆页（memories）：分组展示，删除有确认与撤销。

## 验收标准

- [ ] 等级页当前等级列高亮，切换等级后高亮跟随。
- [ ] 省流模式开关真实生效：开启后全站档位降为 `mo-lite`，并能被用户关闭。
- [ ] 列表错峰入场不超过 300ms。
- [ ] `mo-off` 下无入场动画。

## 禁止事项

- ⛔ 不要给 `about` / `privacy` / `consents` 三个合规页加动效（属 XJ-708，且明确不做游戏化）。
- ⛔ 不要用「限时」「最后 N 名」类胁迫性文案促升级。
