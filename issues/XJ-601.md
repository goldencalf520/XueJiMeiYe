# XJ-601 · 图形资源补齐：维度标识、封面占位、加载环、空状态

> **归属**：设计系统 Agent（`ds`） · **波次**：W6 · 图形资源 · **优先级**：P1 · **规模**：M

> **价值**：把还缺的图形补齐，让档案、周报、加载态、空状态全都有视觉语言，而不是灰色占位。

## 背景

- 现有 47 个彩色图形（Microsoft Fluent Emoji，MIT），已用于首页六维宫格与「我的」页徽章行。
- 仍缺：档案 / 周报的维度标识、封面加载失败占位、加载环、空状态图形。

## 范围与实现要点

1. 新增维度标识图形（对应 肌肤 / 体型 / 轮廓 / 体能 / 体态 / 心灵 六个维度，供雷达图与周报使用）。
2. 新增封面图加载失败 / 空数据占位图形。
3. 新增加载环图形（配合 `gd-spin` 合成动图）。
4. 新增空状态图形（与项目已有 base64 SVG 空状态插画风格协调）。
5. 更新 `scripts/fetch-graphics.js` 的清单并重跑（脚本幂等），同步刷新 `manifest.json` 与 `LICENSE.md`。
6. 保持「资源文件 / `GRAPHICS` 注册表 / `uno.config.ts` safelist」三层严格一致，并跑一致性校验。
7. 同步更新设计文档 09 的替换清单与体积表。

## 验收标准

- [ ] 一致性校验脚本通过：资源文件数 = 注册表项数 = safelist 条数，且本地名与类名后缀一一对应。
- [ ] 新增图形在构建产物中生成 `background:url(data:image/svg+xml...)`（彩色模式），未变成 mask。
- [ ] 图形体积增量 ≤ 20KB（给出实测数值）。
- [ ] `LICENSE.md` 与 `manifest.json` 覆盖全部新增图形的来源与许可。
- [ ] 按 D17，档案页雷达图的维度标识叠加方案在 Issue 内给出结论（图形只能作兄弟节点，不能嵌入 SVG 内部）。

## 禁止事项

- ⛔ 不要引入非 MIT / 非 Apache / 非 CC0 的图标集（如 CC-BY-SA 的 openmoji 有传染性，已排除）。
- ⛔ 不要把图形放到 `src/static/`（会被全量拷贝导致体积翻倍）。
- ⛔ 不要在 `GRAPHICS` 里用模板字符串拼类名（UnoCSS 静态扫不到，图形会静默消失）。
