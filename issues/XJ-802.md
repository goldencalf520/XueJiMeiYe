## 背景

- 已有约束：金底统一配深棕墨字 `--on-brand`（白字对比仅 2.4:1 不达 WCAG）。
- 乐龄模式强制关闭动效，且不提供覆盖入口。

## 范围与实现要点

1. 计算并列出三套皮肤下正文、次要文字、按钮文字、达标条、徽章文字的对比度数值。
2. 任意文字类对比度 <4.5:1、非文字类 <3:1 视为不达标。
3. 实测触控热区 ≥44px（重点检查乐龄与图标按钮）。
4. 验证系统「减弱动态效果」偏好下页面行为（若平台不支持自动读取则记录结论）。
5. 验证乐龄模式下动效全部关闭、字号放大、无信息丢失。

## 验收标准

- [ ] 报告含完整对比度数值表（颜色值 + 比值 + 判定）。
- [ ] 所有不达标项都有明确的整改建议与影响文件。
- [ ] 触控热区抽测结果记录在案。
- [ ] 乐龄模式复查：无动效、字号达标、无内容被裁切。
