## 背景

- `static/images/avatar.jpg` 体积 57.4 KB，全项目零引用（模板遗留）。
- 本轮彩色图形让 `app.wxss` 增加约 59 KB，删除死资源可基本抵消。

## 范围与实现要点

1. 先跑引用扫描，输出「零引用资源清单」到 Issue 评论，再执行删除（先报告后删除）。
2. 按 D16 删除零引用的 `avatar.jpg`（57.4 KB），并记录回收后的包体积。
3. 删除后复测主包体积，输出「删除前 / 删除后」对比。
4. 确认 `.gitignore` 未影响 `src/static/` 的正常跟踪。

## 验收标准

- [ ] 删除前列出零引用清单；清单内每一项都经过二次确认。
- [ ] 删除后引用扫描零命中，构建通过。
- [ ] 主包体积下降 ≥50 KB（给出实测数值）。
