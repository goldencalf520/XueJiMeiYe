## 背景

- 档案页 123 行，主要是数字卡片 + 静态折线。用户看到 78 分不知道是好还是不好。
- 六维定义为：肌肤 / 体型 / 轮廓 / 体能 / 体态 / 心灵。

## 范围与实现要点

1. 总分改为 `XIndexRing` 指数环（按 D8 保留数字滚动，≤600ms 完成）。
2. 趋势折线替换为 `XTrendChart`，可点按查看某日数值。
3. 六维改为 `DimCard`：每维一个卡片，含达标进度条（用 `--meter-*`）+ 一句人话结论（如「达标 55%」「略高于预期」「优秀」）。
4. 滚动触发出场用 `useReveal` / `XReveal`（`mo-reveal` + `is-in`），只播一次。
5. 加载态补骨架屏，形状与真实内容对应，交叉淡入 240ms，不做尺寸跳变。

## 验收标准

- [ ] 指数环、趋势曲线、六维达标条三处都可交互并正确显示数据。
- [ ] 达标条颜色由 `--meter-ok / near / low` 驱动，三皮肤下均可辨。
- [ ] 每个维度都有非技术性的人话结论。
- [ ] 滚动到视口时才播放入场，且不重复播放。
- [ ] 首屏入场 ≤800ms；动画期间无 setData（用开发者工具验证）。

## 禁止事项

- ⛔ 不要使用焦虑性措辞（如「差」「危险」「你落后了」）。
- ⛔ 不要监听 `onPageScroll`，滚动触发只能用 `uni.createIntersectionObserver`。
- ⛔ 不要修改后端档案接口结构。
