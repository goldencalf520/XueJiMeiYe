# XJ-602 · 图标语义枚举固定 + 前端映射层（为 .ic-chip 彩色化铺路）

> **归属**：后端服务 Agent（`be`） · **波次**：W6 · 图形资源 · **优先级**：P1 · **规模**：S
> **状态**：`done` · **认领人**：`win-A`
> **价值**：首页待办图标名来自后端，直接换彩色图形会因为「后端返回了未收录的名字」而显示空白。先把枚举固定下来，彩色化才是安全的。

## 背景

- 首页 `todos` 的图标名由后端返回，前端直接映射到图标类。
- `XGraphic` 是 bg 模式（彩色但不可换色），`XIcon` 是 mask 模式（可换色但单色）—— 两者不可兼得，必须明确分工。

## 范围与实现要点

1. 在后端固定一份图标语义枚举（约 12 个，如 `skin` / `body` / `contour` / `fitness` / `posture` / `mind` / `checkup` / `plan` / `points` / `family` / `store` / `know`）。
2. 后端返回图标时只返回枚举值，不返回具体图标名。
3. 前端新增 `xj/icon-map.ts`：枚举值 → `XGraphic` 图形名（彩色）的映射；未命中时回退到 `XIcon` 单色图标，**绝不出现空白**。
4. 给出「功能性图标继续用 XIcon（箭头 / 勾选 / 表单 / tabbar），情感化图形用 XGraphic」的判断准则文档。

## 验收标准

- [ ] 后端返回的图表枚举全部在映射表覆盖范围内（用脚本或测试断言）。
- [ ] 故意返回一个未收录的枚举值时，前端回退到单色图标而不是空白。
- [ ] 映射表是新增独立文件，不改动任何页面。
- [ ] tabbar / 箭头 / 勾选等换肤相关图标未被改为彩色。

## 禁止事项

- ⛔ 不要改动 tabbar 图标（换成彩色会破坏换肤能力与选中态语义）。
- ⛔ 不要在页面里硬编码图标名绕过映射层。
