## 背景

- 存折页现在是流水列表，看不出增长趋势。
- 5 个游戏页（转盘 / 翻牌 / 问答 / 种树 / 消消乐）风格不统一。

## 范围与实现要点

1. 存折页：加迷你趋势图（复用 `/app/points` 数据，无需新接口）+ 积分获取来源分组。
2. 5 个游戏页统一按压反馈、加载态与结果呈现方式。
3. 游戏结果动画只动 `transform` / `opacity`，`mo-off` 下直接呈现结果（这一点在游戏页尤其重要，乐龄用户可能不玩）。
4. 统一「积分获得」的呈现方式（数字上浮 + 图标）。

## 验收标准

- [ ] 存折页有趋势可视化且与流水数据一致。
- [ ] 6 个页面在 `mo-off` 下首帧完整可读且可正常操作。
- [ ] 游戏结果在任何档位下都能被明确感知（即使没有动画，也要有静态结果展示）。
- [ ] 未修改 `pkg-points/checkin.vue`（属 XJ-401）。

## 禁止事项

- ⛔ 不要修改游戏的核心玩法逻辑与概率。
- ⛔ 不要让游戏结果强依赖动画呈现（`mo-off` 下必须同样清晰）。
