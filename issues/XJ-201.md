# XJ-201 · 首页：连续签到激活条 + 「今日 3 件事」任务卡 + 小镜入口

> **归属**：前端页面 Agent（`fe`） · **波次**：W2 · 主 Tab 体验 · **优先级**：P0 · **规模**：L
> **状态**：`done` · **认领人**：`win-A`
> **价值**：首页是唯一能让人「每天想来打开」的位置。加上签到与今日任务，首页从静态宫格变成有「今天做了什么 / 还没做」的状态回写。

## 背景

- 首页目前是配置驱动的静态宫格：图标 + 文字，没有当日状态，也没有「做了给什么」的即时反馈。
- 签到、任务、积分三个体系后端已存在，缺的是首页的展示与状态回写。

## 范围与实现要点

1. 新增「连续签到」激活条：金色渐变底，左「已连续签到 N 天」大数字，右「本月已签 M 天」，未签今日时显示「去签到」，已签则显示今日已得积分。
2. 新增「今日 3 件事」任务卡：三项任务带进度环，完成项降级为灰字 + `✓`；数据来自后端动态生成（XJ-305）。
3. 问候栏右侧接入 `XMascot`（32px，online 态）作为魔镜入口；按 D21 **保留现有 `mirrorFab` 悬浮球**，头像为第二入口（标准皮肤下两者并存，乐龄下移交给 XJ-203 的语音条）。
4. 入场动效复用 `mo-rise` + `mo-d1~6` 错峰；进度环变化走 `mo-grow-x`（只动 transform 与 opacity）。
5. 按压反馈用原生 `hover-class="mo-press-active"` + `hover-stay-time="80"`，不用 CSS `:active`（小程序不支持）。

## 验收标准

- [ ] 未签到 / 已签到两种状态下激活条文案与样式都正确。
- [ ] 任务完成后进度环有过渡，且完成后刷新页面状态保持。
- [ ] 点击激活条跳签到日历、点击小镜跳魔镜、点击任务跳对应页面。
- [ ] 标准皮肤下问候栏头像与 `mirrorFab` 悬浮球**同时存在且都能进入魔镜页**（按 D21）。
- [ ] `mo-off`（乐龄）档位下无入场动画，内容首帧即可读。
- [ ] 漏签只显示「从今天继续」，页面无倒计时、无催促文案。

## 禁止事项

- ⛔ 不要在首页监听 `onPageScroll`，也不要在滚动回调里 setData。
- ⛔ 不要做倒计时、连签中断惩罚、裂变诱导（健康产品不做焦虑驱动）。
- ⛔ 不要让 `HomeRender.vue` 超过必要改动——它是本 Issue 独占文件，其他 Issue 需在本 Issue 合并后再改。
