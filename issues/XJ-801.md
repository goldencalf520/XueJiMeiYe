## 背景

- 性能预算是：首屏入场 ≤800ms、并发动画 ≤12 个、动画期 0 次 setData、帧率 ≥55fps。
- 低端机走 `mo-lite` 档位（`benchmarkLevel` ≤20），iOS 与取不到值时按满配处理不误降级。

## 范围与实现要点

1. 在至少一台低端 Android（`benchmarkLevel` ≤20）与一台 iOS 上实测。
2. 测量并记录：首屏入场耗时、动画期间 setData 次数、并发动画峰值、滚动帧率、最低帧率。
3. 验证档位降级链路：`mo-full` → `mo-lite`（低端机 / 省流）→ `mo-off`（乐龄强制）。
4. 验证「取不到 benchmarkLevel」时不误降级。
5. 输出报告含表格 + 截图 + 结论（是否放行）。

## 验收标准

- [ ] 报告给出四项预算的实测值与判定（达标 / 不达标）。
- [ ] 若某项不达标，给出具体到文件与类的定位。
- [ ] 确认动画期间 setData 次数为 0（关键项）。
- [ ] 确认乐龄与低端机路径确实降级，iOS 未被误降级。
- [ ] 报告可作为后续性能回归的基线。
