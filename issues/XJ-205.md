# XJ-205 · 魔镜页人格化改造：小镜头像 + 状态 + 回复内行动卡

> **价值**：魔镜是小程序最有差异化的功能，但现在是纯文字流。给它一个固定的「人」和可执行的动作卡，陪伴感才立得住。

## 背景

- 魔镜页 248 行，本质是消息流；AI 回复是一大段文字，用户看完不知道下一步做什么。
- 小镜形象组件（XJ-105）提供形象，本 Issue 负责让它「活」在页面里。

## 范围与实现要点

1. 页面头部改为固定的小镜头像（`XMascot`，48px）+ 在线状态 + 「今日已聊 N 轮」。
2. 状态联动：等待回复时 `thinking`，流式输出时 `speaking`，空闲时 `online`。
3. 回复中的可执行内容抽成 `ActionCard.vue`：如「4-7-8 呼吸法」「喝水提醒」「拉伸 3 分钟」，卡片可直接点击触发对应动作或跳转。
4. 长回复折叠：默认显示摘要 + 「展开全文」，避免一屏全是文字。
5. 消息入场用 `mo-cross` 交叉淡入；发送/接收的反馈走 `mo-press`。

## 验收标准

- [ ] 头部小镜头像在三种状态下正确切换（提供截图）。
- [ ] 回复中出现行动卡时可点击并产生正确行为；纯文字回复不受影响。
- [ ] 超过阈值的长回复默认折叠，可展开。
- [ ] 乐龄下头像与字号同步放大，无入场动画。
- [ ] 流式输出期间不触发全页 setData（仅消息区更新）。

## 禁止事项

- ⛔ 不要在消息流里嵌套滚动容器制造双滚动条。
- ⛔ 不要在流式输出时用整页 setData 刷新。
- ⛔ 不要修改魔镜后端接口（本轮不动 `mirror.service.ts`）。
