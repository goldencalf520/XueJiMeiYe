# XJ-405 · 六维周报：夜色黑金封面 + 六维环比 + 可分享

> **价值**：周报是「被珍藏」的内容形态，也是家人之间自然传播的载体。夜色黑金让它与日常页面区分开。

## 背景

- 档案体系已有趋势、报告、时间轴等页面，缺少「周期性总结」这一层。
- 设计要求封面固定夜色黑金（用 `--report-*`），不随皮肤变化，形成「报告 = 珍视」的视觉语言。

## 范围与实现要点

1. 封面卡：夜色黑金（`--report-bg` / `--report-ink`）；左指数 + 环比，右雷达图；右上角「第 N 期」。
2. 本周三件事：做得不错（绿）/ 需要留意（琥珀）/ 下一步（金），复用 assess 的 `three` 结构。
3. 六维变化：6 行，每行「色块 + 维度名 + 进度条 + 环比（`+4` / `持平`）」。
4. 操作：「分享给家人」+「看看上期」。
5. 合规：底部固定「品牌指数，不是医学指标」。
6. 按 D5 本 Issue 只做站内页面，不做订阅消息推送。

## 验收标准

- [ ] 封面在三套皮肤下都保持夜色黑金（不随皮肤变化）。
- [ ] 六维环比数值与后端一致，改善 / 持平 / 下降三种状态可辨。
- [ ] 「看看上期」能取到上一周数据。
- [ ] 底部合规声明固定可见（不随滚动消失）。
- [ ] 分享动作可用且分享内容不含个人敏感健康数据。

## 禁止事项

- ⛔ 不要使用焦虑性措辞表述「下降」。
- ⛔ 不要做医学指标暗示（必须声明为品牌指数）。
- ⛔ 不要让封面跟随皮肤变化（这是刻意设计）。
