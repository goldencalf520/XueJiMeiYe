# XJ-208 · 测评流程可视化：答题进度环 + 雷达生长 + 结果分维度卡片化

> **归属**：前端页面 Agent（`fe`） · **波次**：W2 · 主 Tab 体验 · **优先级**：P1 · **规模**：M
> **状态**：`done` · **认领人**：`win-C`
> **价值**：测评是转化入口，现在的答题过程没有进度感，结果页是一堆数字。加进度环与雷达生长，完成率和可读性都会提升。

## 背景

- 答题页无进度提示，用户不知道还剩多少题。
- 结果页的雷达图是静态 SVG，且结果以数字罗列呈现，缺少「分维度」的叙事。

## 范围与实现要点

1. 答题页顶部加进度环（复用 `XIndexRing` 或轻量版），随题号实时更新。
2. 结果页雷达图加从中心生长的动画（`stroke-dashoffset` 或 `scale`），`mo-off` 下直接呈现。
3. 结果页改为分维度卡片化：每维一卡，含得分、结论、建议。
4. 按 D17 为雷达图叠加维度图形（图形只能作为兄弟节点，不能嵌入 SVG 内部）。
5. 注意：紧急就医页 `pkg-assess/urgent` **不做入场动画**（本 Issue 不改该文件）。

## 验收标准

- [ ] 进度环随题号更新且与实际进度一致。
- [ ] 雷达生长动画在 `mo-full` 播放、`mo-off` 跳过。
- [ ] 结果页每个维度都有独立卡片与结论。
- [ ] `pkg-assess/urgent` 未被改动。

## 禁止事项

- ⛔ 不要改动 `pkg-assess/test-balance.vue` / `test-chair.vue`（属 XJ-702）。
- ⛔ 不要在雷达图 SVG 内部嵌套外部图形（小程序不支持）。
- ⛔ 不要给紧急页加入场动画。
