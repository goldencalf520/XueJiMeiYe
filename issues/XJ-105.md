## 背景

- 魔镜页是纯文字流，AI 回复没有「人」的形象载体，缺乏陪伴感。
- 方案要求「先用 CSS 合成头像」，不引入图片资源——零包体积、三皮肤可自动换色。

## 范围与实现要点

1. 新建 `XMascot.vue`：金色渐变圆底 + 镜面高光 + 两点眼 + 弧线微笑 + 淡腮红，纯 CSS 几何合成，零图片资源。
2. Props：`size`（32 / 48 / 72 / 88）、`state`（online / thinking / speaking / night）、`tone`。
3. 四态差异：online 带在线绿点；thinking 外圈旋转；speaking 显示声波；night 切夜色金配色。
4. 三皮肤适配走继承的自定义属性（定义在 `style/mascot.scss` 的 `page,.xj` / `.xj.elder` / `.xj.night`），组件内不写 `.elder` / `.night` 选择器。
5. 乐龄：描边加粗到 3px、五官放大 15%。
6. thinking 的旋转属于「状态指示」而非装饰，乐龄下保留（与动效档位降级规则一致）。

## 验收标准

- [ ] 四个尺寸 × 四个状态在柔金 / 乐龄墨绿 / 夜色金三种底色上都能辨认（提供截图矩阵）。
- [ ] 组件在任意页面引入即可正确渲染，无需页面额外传皮肤 class。
- [ ] 乐龄模式下描边与五官按规格放大。
- [ ] `mo-off` 档位下 thinking 的旋转仍保留（状态指示），其余装饰性动画停止。
- [ ] 零图片资源、零新增依赖。

## 禁止事项

- ⛔ 不要引入任何图片或字体图标作为小镜形象。
- ⛔ 不要在组件内写皮肤选择器（`.elder` / `.night`），必须走继承变量。
- ⛔ 不要用 `<svg>` 标签（小程序不支持）。
