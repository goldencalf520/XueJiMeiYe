## 背景

- `home.service.ts` 已按 `data.components` 生成首页配置，具备编排能力，但还没有「今日任务」模块。
- 按 D1 决议执行：依当期六维短板 + 待办（体检券 / 测评 / 方案）动态生成，不使用固定文案。

## 范围与实现要点

1. 在 `home.service.ts` 中新增「今日 3 件事」生成逻辑：优先取六维短板，其次取待办（未用体检券 / 未完成测评 / 方案里的日常小事）。
2. 最多返回 3 项，已完成项从今日清单剔除。
3. 每项返回：`code`、标题、副标、目标值 / 当前值、跳转路径、图标语义枚举。
4. 访客返回空数组（首页不展示任务卡）。
5. 结果随 `GET /app/home` 一起下发，不新增接口。

## 验收标准

- [ ] C / B / A 会员返回 3 项任务，访客返回 0 项。
- [ ] 已完成的任务不在清单中；完成任务后刷新首页确实少一项。
- [ ] 每项都带可用的跳转路径，点击可达。
- [ ] 生成逻辑对「无档案 / 无方案」的新用户有兜底任务（按 D1：降级为「完成首次六维测评」）。

## 禁止事项

- ⛔ 不要新增数据表或新接口。
- ⛔ 不要返回固定文案（必须与用户数据相关）。
- ⛔ 不要返回倒计时类任务（健康产品不做焦虑驱动）。
