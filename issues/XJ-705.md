## 背景

- 家人模块已有 `list` / `view` / `accept` 三页，但缺少统一头像与健康状态表达。
- 接力棒新页面（XJ-402）需要从家人列表顶部进入。

## 范围与实现要点

1. 家人头像统一用 `XMascot` 合成（不引入图片资源）。
2. 家人列表加健康状态点（正常 / 需留意 / 待跟进），用语义色而非纯装饰色。
3. 家人列表顶部加接力棒入口（卡片形式，数据读 XJ-304 的接口）。
4. 家人健康页（view）复用档案页组件（`DimCard` 等）保持表达一致。
5. 邀请页（accept）保持简洁，不做动效堆叠。

## 验收标准

- [ ] 头像全部为 CSS 合成，无图片资源。
- [ ] 三个页面的健康状态点在四种状态下可辨。
- [ ] 家人列表顶部接力棒入口可跳转且显示真实接力状态。
- [ ] `mo-off` 下无入场动画。

## 禁止事项

- ⛔ 不要修改 `pkg-family/relay.vue`（属 XJ-402）。
- ⛔ 不要用颜色单独承载健康状态语义（需配文字或图形，兼顾色觉障碍）。
