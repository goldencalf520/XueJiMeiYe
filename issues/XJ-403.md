## 背景

- 组件层已就绪：`XBadge` 支持未解锁（Tabler 线稿 + 虚线盘）/ 已解锁（彩色图形 + 金环）/ 新解锁（弹入 + 光晕）三态。
- 「我的」页已接入 4 枚徽章作为试点，本 Issue 做完整徽章墙。

## 范围与实现要点

1. 顶部进度：`XIndexRing` 或 SVG 圆环显示「已点亮 8 / 24」+ 下一称号提示（再点亮 2 枚解锁「健康达人」）。
2. 分组 Tab：坚持 / 探索 / 分享；选中金底白字，其余白底描边。
3. 徽章网格 3 列：已解锁 = 彩色图形 + 名称；未解锁 = 灰底虚线 + 锁形 + 名称 + 迷你进度条 + `19/30`。
4. 点击展开详情：图标 + 名称 + 解锁条件 + 点亮日期 + 「分享给家人」/「看别人点亮」。
5. 点亮动效 `scale(0.8 → 1.05 → 1)` 400ms，乐龄下直接呈现。

## 验收标准

- [ ] 三种徽章状态（未解锁 / 已解锁 / 新解锁）都能渲染，与「我的」页试点一致。
- [ ] 分组 Tab 切换正确，未解锁徽章显示真实进度而非占位数字。
- [ ] 详情展开信息完整，分享动作可用。
- [ ] 乐龄下 3 列网格不溢出，徽章与文字同步放大。
- [ ] 24 枚徽章的图形全部来自已登记的 `GRAPHICS` 注册表（不出现空图形）。
