## 1. 验收方法

- **对比度**：从 `apps/miniapp/src/style/index.scss` 摘取三皮肤令牌定义值（std `page` 默认段 / `.xj.elder` / `.xj.night`），
  按实际消费组合（文字色 × 底色）逐对计算 WCAG 对比度；主按钮为渐变底（`--brand-hi → --brand → --brand-dark`），
  按**最不利端 `--brand-hi`** 判定。
- **热区**：量取源码中交互元素的 `height` / `min-height` 实际值；栅格热区（消消乐棋盘）按 375px 视口推算。
- **动效**：核对 `xj/motion.ts` 档位设计与 `xj/store.ts` 的接线现状。
- 只出报告与整改建议，不修改业务代码（XJ-802 禁止事项）。

## 5. 系统「减弱动态效果」偏好 · 平台能力结论

- **结论：微信小程序平台不提供读取系统「减弱动态效果」偏好的 API**。`wx.getSystemSetting()` / `uni.getDeviceInfo()` 仅暴露蓝牙 / 定位 / WiFi / 屏幕方向 / benchmarkLevel 等能力，iOS `NSAccessibilityReduceMotionStatus` 与 Android「移除动画/动画时长缩放」均不可读（实测 API 面核对，`xj/motion.ts` 的 `readBenchmarkLevel` 亦无此通道）。
- **项目替代方案（已实现，`xj/motion.ts`）**：
  1. 三档位体系：`full` 满效 / `lite` 低端机自动降级（Android benchmarkLevel < 20）/ `off` 关闭；
  2. **乐龄模式强制 `off` 且不提供覆盖入口**（detectTier 首行短路，符合 docs/08 §7）；
  3. 「我的 → 省流模式」手动开关（`setTier` 持久化 `xj_mo_tier`），作为用户显式「减弱动效」的入口。
- **后续动作**：关注微信开放该能力时接入 `detectTier` 优先级链（系统偏好 > 用户显式 > 设备等级）。

## 6. 乐龄模式复查

| 检查项 | 结果 | 证据 |
|---|---|---|
| 字号：正文 ≥19px | **✓** | `.xj.elder` 阶梯 body 19 / title 30 / hero 36，最小注释字号 xs 15px（index.scss L136-143） |
| 行高与折行 | **✓** | elder 行高 1.7；标题 `text-wrap: balance` 防单字孤行；`.tag.promo white-space: normal` 乐龄下允许折行（L259、L372） |
| 热区 ≥60px | 部分 ✗ | 主按钮/选项/列表行达标；`.btn.small` 46px、`.pill` 38px、7×7 tile ≈37px 不达（见 §4） |
| 动效全部关闭 | **✗ 未全关（P0）** | 见下 |
| 无内容裁切 / 信息丢失 | **✓**（接线修复后） | off 档设计为「直接呈现终态」：XJ-707 六页 off 分支均保留终态与文字反馈（转盘不转直接弹结果卡、+N 积分以通关弹层文字兜底、shake 不播但棋盘不变）；`useReveal` off 时 `shown=true` 直接呈现 |

**动效未全关的证据链**（整改建议即 XJ-707 交付记录中的跨卡遗留）：

1. `xj/store.ts` 的 `pageClass` 仅含 `['xj', elder?'elder':'std', night?'night']`——**不含 `mo-off` 档位 class**，motion.scss 的 `.mo-off .mo-rise { animation: none }` 等抑制规则全站不生效；
2. `setElder()` 未调用 `syncMotion(elder)`，store 亦未导出 `moTier`；
3. 因此 `checkin.vue` / `achievements.vue` 等六页外页面引用的 `xj.moTier` 为 `undefined`，`xj.moTier === 'off'` 门控恒 false——**乐龄模式下月历入场、金蛋脉冲、+N 上浮提示等动效照播**；
4. 唯一例外：XJ-707 的 6 个页面（passbook / wheel / cards / quiz / tree / match3）在页内自行接线（`syncMotion(xj.elderMode)` + 根节点 `mo-${mo}`），乐龄下正确关闭。

**整改建议**（一处改动全站生效）：`store.ts` 增加 `moTier = ref(syncMotion(elderMode))` 导出；`setElder()` 内同步 `moTier.value = syncMotion(v)`；`pageClass` 追加 `motionClass()`。验收方式：乐龄模式下月历/金蛋应无动画、`+N` 改为 toast/文字反馈。
