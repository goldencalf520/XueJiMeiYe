## 1. 验收方法

- **静态审计**：逐页清点动效类（`mo-rise` / `mo-fade` / `mo-reveal` / `gd-*` / 常驻动画），
  核对 `motion.scss` 时长阶梯与错峰封顶；审计全部 JS 驱动动画（`requestAnimationFrame` / `setInterval`）。
- **运行时探针**：`.preview/XJ-801_tier_probe.mjs` —— esbuild 打包**真实** `apps/miniapp/src/xj/motion.ts`
  （vue 桩替身），对 `globalThis.uni` 注入 15 种设备/存储桩逐一定义加载，覆盖 docs/08 §6.3 降级决策树全分支。
- **真机项**：帧率（≥55fps 连续 3 次取最小）与入场 transitionend 需真机，当前无设备，
  按 §7 方法论列为补测项；静态代理指标（并发数、动画属性白名单、无禁则模式）已全部先行验证。
- 只出报告与整改建议，不修改业务代码（XJ-801 禁止事项）。

## 2. 预算一：首屏入场 ≤ 800ms —— ✓

**静态上界推导**（`style/motion.scss`）：

| 档位 | enter 时长 | 错峰封顶 | 上界 |
|---|---|---|---|
| full | `--mo-enter` 320ms（L27） | `--mo-step` 60ms × 封顶 5 步 = 300ms（L132-149，`mo-d1~d6` 中 d5/d6 同为 ×5；`staggerStyle()` max=300ms 封顶，motion.ts L111-112） | **620ms** |
| lite | `--mo-enter` 归 160ms（L53） | `--mo-step` 归 0ms（L52） | **160ms** |
| off | 全部时长归 1ms + `--mo-hide/--grow` 翻终态（L59-70） | 0 | **≈1ms（直显终态）** |

- 最不利页为错峰最深的多卡页（如 `pkg-points/checkin.vue` 任务卡 `mo-d4` 起）：
  320ms 动画 + 300ms 延时 = **620ms ≤ 800ms**，为真机渲染与首帧留出 180ms 余量。
- JS 图表入场（档案页指数环/趋势图生长 800ms）属 D8 记录在案的例外（§4），不计入 CSS 入场预算。
- 真机 transitionend 实测待补（§7）；静态界已收敛。

## 3. 预算二：并发动画 ≤ 12 个 —— ✓

**全站 53 页逐页普查**（`mo-rise` / `mo-fade` 静态类计数 + `v-for` 内动画元素展开评估）：

| 页面 | CSS 入场动画 | JS 动画 | 常驻动画 | 峰值估计 |
|---|---|---|---|---|
| `pages/me/index.vue` | 9（全站最高） | 0 | 0 | **9** |
| `pkg-family/list.vue` | 7 静态 + 家人卡 `v-for`（mo-d2，活跃+待审两段，典型 ≤6 张） | 0 | 0 | ≤ 11 |
| `pkg-assess/intro.vue` | 7 | 0 | 0 | 7 |
| `pkg-family/relay.vue` / `pkg-module/store.vue` 等 | ≤ 7 | 0 | 0 | ≤ 7 |

| `pkg-game/wheel.vue` | 少量 | 转盘 **1 次** setData 触发 + CSS transition 4s（L67/L178，正确模式） | 加载环 gd-spin 仅加载态 | 低 |

- **结论：全站并发动画峰值 ≤ 11（家人列表页最不利），≤ 12 预算达标。**

## 4. 预算三：动画期 `setData` = 0 —— ✗ 例外登记（P1）

**CSS 驱动路径（全站入场/反馈/状态切换）：达标。**
触发动画只需 1 次类切换/样式绑定写入（如 `.is-in`、`angle.value += …`），动画期间 0 次数据写入。

**JS 驱动例外（2 处，均为「小程序 `<svg>` 不可用 → SVG data-URI + image 渲染、SMIL/CSS 动画不播放」的平台妥协，D8 记录在案）：**

| # | 位置 | 模式 | 量化 | 判定 |
|---|---|---|---|---|
| E1 | `components/chart/XIndexRing.vue` L74-91/L114-136 | rAF 每帧写 `progress/displayNum` → 重生成 SVG data URI 更新 `:src` | 800ms ≈ **48 次 setData**（60fps 口径），每帧 payload ≈ 0.7KB（SVG 字符串），总计 ≈ 34KB | 例外 |
| E2 | `components/chart/XTrendChart.vue` L180-201 | 同模式（`grow` 每帧 → `:src`） | 800ms ≈ 48 次，payload 同量级 | 例外 |

**关键偏差（整改建议 R1）**：D8 决策要求「`mo-off` / **`mo-lite`** 档位与乐龄模式下直接显示最终值」，
但两组件只判 `getTier() === 'off'`（XIndexRing L64/L95、XTrendChart L194）——
**lite 档（低端机）下环/线仍逐帧生长**，恰在性能最差的设备上做了最多的 setData。
消费侧 `pages/archive/index.vue` L31 `countUp = xj.moTier === 'full'` 只让数字静止，未拦环生长。
**建议**：两组件将跳过条件由 `=== 'off'` 收紧为 `!== 'full'`（一行改动，lite 直显终值，D8 对齐）。

**内容型定时器（非动效，不计入预算，记录在案）：**

| 位置 | 模式 | 定性 |
|---|---|---|
| `pages/mirror/index.vue` L257-270 `stream()` | 30ms 打字机流式输出 | 内容流式（仅写当前消息 content，页面自注验收标准 5），非动效 |
| `pages/mirror/index.vue` L172 呼吸引导 | 1s 倒计时 | 用户触发的引导计时 |
| `pkg-assess/test-balance.vue` L34 / `test-chair.vue` L35 | 200ms 秒表 | 用户触发的体测计时 |

## 5. 预算四：帧率 ≥ 55fps —— 待真机补测（静态代理全过）

当前无真机。已完成的**静态代理指标**（帧率风险的先验面）：

1. 并发动画 ≤ 12（§3）✓；
2. 全部 `@keyframes` 只动 `transform` / `opacity`（`motion.scss` L75-120 逐一核对：
   xj-rise / xj-fade / xj-pop / xj-grow-x 全合成器友好；唯一例外 `xj-sheen` 动 `background-position`，
   属一次性 1600ms 装饰扫光，off 档归 1ms，lite 档被显式关闭 `animation: none`，`graphics.scss` L344-351）；
3. 无 `will-change` 常驻（全站 0 处）、无 `onPageScroll` 监听（全站 0 处，仅类型声明与注释）、
   无 `.mo-off *` 式通配档位覆盖（`motion.scss` 兜底规则全部点名 `.mo-*` 类）；
4. 滚动触发一律 `uni.createIntersectionObserver`（`useReveal`，motion.ts L143），回调内只改 1 个布尔。

**判定**：静态风险面全部收敛，真机帧率按 §7 方法补测后回填本表；因无高风险模式，**不作为发布阻断项**。

## 9. 真机补测方法论（有设备时执行，回填 §0/§5）

1. **帧率**：微信开发者工具「真机调试」→ 性能面板；中低端 Android（benchmarkLevel ≤ 20）与 iOS 各一台；
   走查页：档案页（含双图表）、家人列表（并发最高）、徽章墙（24 枚网格）、消消乐（连续消除）；连续 3 次取最小值 ≥ 55fps。
2. **入场耗时**：档案页与签到页，首帧 → 最后一个入场元素 transitionend，≤ 800ms（静态上界 620ms）。
3. **降级**：Android 真机读 `uni.getDeviceInfo().benchmarkLevel` 确认 ∈ [1,20) 时档案页环/数字直显（若 R1 已修），
   iOS 确认满效；乐龄模式确认月历/金蛋/上浮提示全静止。
4. **setData**：开发者工具 Audits 面板录档案页入场，确认 lite 档 0 次 setData（R1 修复后）。
5. 将实测值回填本报告 §0 表格并在 §5 记录设备型号与 WeChat 版本。
