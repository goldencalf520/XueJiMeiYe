## 1. 走查方法

- **矩阵静态走查**：9 个关键页面逐页核对①皮肤载体（根节点 `:class="xj.pageClass"`）②颜色消费方式（令牌变量 vs 固定组合）③乐龄/夜色特有组件路径。
- **产物断言**：win-A 全新构建 `dist/build/mp-weixin/app.wxss`，14 项断言覆盖三皮肤变量块、三档尺寸/圆角、夜色底座覆盖、动效兜底（脚本内联于 `.preview/XJ-803_wxss_assert.txt`，构建命令 `env -u VSCODE_CWD npx uni build -p mp-weixin`，规避 IDE 终端丢 tabler 规则的已知问题；本次 **i-tabler 规则引用 121 条**完好）。
- **对比度计算**：`.preview/XJ-803_graphics_contrast.mjs`（可复跑，输出存档 `.txt`）——从六维图形 SVG 逐 `fill` 提色，对夜色卡底 #262019 / 白卡底 #ffffff 计算 WCAG 对比度；徽章合成色计算同 XJ-802 方法（alpha 混合后取对比度）。
- 只出报告与整改建议，不修改业务代码（XJ-803 禁止事项）。

## 3. 图标底座三档专项（AC#1）

**单一变量源（D13）验证**：三档尺寸/圆角只在一处定义——graphics.scss L28-30（std `--gd-size-sm/md/lg: 28/38/46`、`--gd-r-*: 10/13/16`）与 L90-92（elder 覆盖 `34/46/56`、`12/15/18`），`.ic-chip`（index.scss L547-551）、`.icon-box`（graphics.scss L77-86）、`.xg-chip`（L254+）三种实现**全部消费同一组变量**，产物断言 4 项全过。

**引用点对齐与溢出**（全站消费点普查）：

| 消费模式 | 代表位置 | 三档跟随 | 判定 |
|---|---|---|---|
| `.ic-chip`（lg 46/56） | HomeRender L238、me 页功能格 | 底座 ✓ | ✓（乐龄行高 ≥64px 容纳 56px，无溢出） |
| `.ic-chip.sm`（28/34） | HomeRender L305/L314 等 | 底座 ✓ | ✓ |
| `.icon-box`（md 38/46） | relay 周格子、box、mirror、档案卡 | 底座 ✓ | ✓ |
| `.xg-chip` sm/md/lg | 图形底座（含 `--gd-chip-ring` 描边） | 底座+描边 ✓ | ✓ |
| 徽章盘（56/68/80） | achievements 三列格（格宽 ~100px） | ✓ | ✓（乐龄 68px 仍留余量，XJ-403 复核） |

**✗ 偏差 1 处（P2）**：底座内嵌单色图标为固定像素（`XIcon` 内联 `fontSize` 恒覆盖底座 font-size）——
`HomeRender.vue` L238（chip 46/56 内固定 24px）、L305（28/34 内固定 18px）、L314（28/34 内固定 22px）。
乐龄档底座放大 20% 而内图形不跟随，占比 0.52→0.43 / 0.64→0.53，**不溢出不裁切，仅视觉比例偏小**。
建议（R1）：这三处改传 `calc` 串或让 `XIcon` 支持 `1em` 继承底座 font-size。其余消费点（me 页、archive 等）内图形占比经抽查无同类偏差。

## 4. 徽章三态 × 三皮肤专项（AC#2）

`XBadge.vue` 三态结构（L40-57）：锁定 = 虚线环 + 灰度线稿 `--xb-locked-ink`；解锁 = tone 渐变盘 `--xb-disc` + 彩色图形；新解锁 = 解锁 + `gd-pop` 弹入 + `gd-halo` 光晕（420/900ms 一次性）。三皮肤均有专属变量块（产物断言过）。

**逐皮肤逐态可辨性**（WCAG，方法同 XJ-802）：

| 皮肤 | 锁定态 | 解锁态 | 新解锁态 |
|---|---|---|---|
| 标准 | 线稿 `#b6ada3` on `#fdf6e9` 盘 = **2.06:1** < 3:1——刻意弱化的锁定态，语义由结构承载（虚线环 + 进度环 + `progress/target` 文字 achievements.vue L125），线稿为装饰冗余，按 WCAG 1.4.11 豁免口径放行 | 彩色图形 on 金盘（主体色 ≥5:1）✓ | 弹入 + 金色 halo（420/900ms 一次性）✓ |
| 乐龄 | 线稿 `#a9a29a` on 白盘 = **2.52:1**（同上豁免口径）；盘径放大 56/68/80 | ✓ | ✓（动效按 D8：乐龄下 gd-pop 保留静态放大终态） |
| 夜色 | 线稿合成 rgba(240,231,214,.42) on 盘底 = **3.25:1** ✓（图形界达标，三皮肤中最优）；**标签合成 3.79:1 ✗ < 4.5:1** | 彩色图形 on 半透明金盘 ✓（主体色夜底 5.21-10.42:1，§5 表） | ✓ |

**唯一不达标**：夜色锁态标签 3.79:1 —— 与 **XJ-802 §3 ⑧**（其口径 4.48:1 边界不达标）**同根因同位置**，该报告已建议改 `--ink-2`，本报告确认数值并并入该项整改，不另立重复条目。

## 5. 彩色图形深底可辨性专项（AC#4）

**消费模式分两类**：

1. **带底座**（`.xg-chip` / `.dim-ic` / `.thumb`）：夜色下底座为「半透明金底 + `--gd-chip-ring` 描边提亮」（docs/09 §8 适配矩阵的既定方案，graphics.scss L127-160 + L254），彩色图形落点为金调深底，主体色对比 5.21-13.45:1 ✓。
2. **裸图形**（`DimCard.vue` L50 30px、`pkg-assess/result.vue` L140 20px、`XRadar.vue` L118 18px、me 页 22px）：docs/09 L185 认可的裸用形态（伴随文字标签承载语义）。

**六维图形逐色计算**（`.preview/XJ-803_graphics_contrast.mjs`，fill 色对夜色卡 #262019 / 白卡 #ffffff）：

| 图形 | 色数 | 夜色底 | 白卡底 | 判定 |
|---|---|---|---|---|
| dim-skin | 1 | 8.32 ✓ | 1.94 ✗ | 装饰锚点（有伴随标签），豁免口径 |
| dim-shape | 2 | 5.21-10.42 ✓ | 1.55 ✗（亮黄）/3.09 ✓ | 同上 |
| dim-contour | 6 | **2.73 ✗（#1c5cd7 暗面）**，余 3.98-13.45 ✓ | 1.20-4.04 混合 | 暗面为晶体明暗分面，主体 5.89 ✓ |
| dim-fitness | 1 | 6.51 ✓ | 2.48 ✗ | 装饰锚点 |
| dim-posture | 3 | 5.80-10.77 ✓ | 1.50-2.78 ✗ | 装饰锚点 |
| dim-mind | 2 | 主体 8.83 ✓；**细节 #402a32 1.22 ✗** | 细节 13.16 ✓；主体 1.83 ✗ | **✗ P2：夜色下面部眉/嘴线不可辨，图形退化为纯黄圆；白卡下则主体偏淡** |

**判定与建议**：裸图形均伴随维度名文字标签（语义由文字承载，图形为装饰性强化，WCAG 1.4.11 装饰件豁免），**不构成阻断**；但 **dim-mind 的双向缺陷（夜色丢细节 / 白卡主体淡）** 记录为 P2（R2）——
建议二选一：①给 `DimCard` / `result` 的裸图形套 40px `.dim-ic` 底座（weekly.vue L149/L252 已示范，零新样式）；②重制 dim-mind（深色细节线提亮 + 主体加深）。
另记录：白卡下 5/6 图形主体色 <3:1 属「彩色淡色块」固有形态，全站一致且从未作为功能唯一载体，按装饰口径放行。
